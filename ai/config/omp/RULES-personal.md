# Personal rules (every repository)

- Commits follow Conventional Commits: `<type>(<optional scope>): <subject>`. Subject imperative, lowercase, no trailing period, 72 characters at most; the body says why. One logical change per commit. Use the repository's own types and scopes when it lists them.
- Never add a co-author trailer, or a "Generated with" line to commits or pull request bodies.
- No secrets, credentials or customer data in commits.
- Everything written into a repository is in English (code, comments, commits, docs, logs, test names), whatever language the request was in; only the conversation follows the user's language.
- Never push, publish, release or start a CI workflow unless asked.
